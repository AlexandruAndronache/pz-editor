Install

    

      
    
        
  1. Unzip the download into C:\Users\<you>\Zomboid\mods\, so you get mods\MyFirstMod\mod.info.
    2. 
        
  2. Start the game, open Mods, and enable your mod. For an existing save: Load → pick the save → More → Mods.
    3. 
        
  3. Each file replaces the whole vanilla file at the same path. After a game update, open the editor again, redo or restore your edits, and download a fresh zip.
    4. 
        
  4. If something doesn't load, search C:\Users\<you>\Zomboid\console.txt for the file name or ERROR.
    5. 
      

      
Changes are stored only in this browser. Clearing site data or using another browser starts an empty mod.
